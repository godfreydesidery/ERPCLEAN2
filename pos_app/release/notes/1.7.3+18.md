**OrbixPOS now runs on Android** - Android POS devices (Sunmi, iMin, Telpo and similar) and
Android tablets. Works with the same ERP server as 1.7.2 (no server update needed), including a
plain http server on the shop's network (for example http://192.168.1.10:8081).

**Printing on an Android device.** The built-in receipt printer of most Android POS devices shows
up as a paired Bluetooth printer (on Sunmi it is called "InnerPrinter"). In Server setup, choose it
as the receipt printer; in the restaurant Settings, choose it for a kitchen or bar station if the
device prints slips. Standalone Bluetooth receipt printers work the same way once paired in Android's
Bluetooth settings. Network printers (an IP address, port 9100) work as on Windows. The first time,
Android asks to allow "Nearby devices" - answer Allow, or printing cannot reach the printer.

**Installing on Android:** copy the APK to the device and open it (allow installing from this source
when Android asks). Then tap the version text at the bottom of the sign-in screen seven times to open
Server setup, enter the ERP address, and test the connection.

**On Windows** nothing changes in this version.

**Before rolling out,** on one Android device:

- check the version at the bottom of the sign-in screen reads 1.7.3+18;
- sign in, open Server setup, choose the built-in printer and press Test print;
- ring a sale (or bill a table) and print the receipt.
