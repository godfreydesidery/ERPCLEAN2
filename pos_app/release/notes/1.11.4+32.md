**No server update needed.** Works with any server the tills already use.

**Kitchen and bar slips no longer print twice.** On a till that prints its own orders AND has
"Print ALL ... slips here" ticked (Restaurant > Settings), pressing Send sometimes printed both the
kitchen and the bar slip twice. The till's own Send and its every-5-seconds check for new slips
could both pick up the same slip while a Bluetooth printer was still busy. Now every slip is
marked as taken before any of them goes to a printer, and Send waits for a slip that is already
printing instead of printing it again.

Also fixed:

- reopening the app within a minute of an order no longer prints that minute's slips again;
- pressing Reprint in the "Some slips did not print" box no longer gives an extra copy when the
  till has already printed the slip by itself in the meantime ("Printed" shows instead);
- Android: a slip that reached the printer is no longer reported as failed (and printed again)
  when the Bluetooth link drops at the very end.

"Reprint" on the order still always prints.

Includes 1.11.3 (customer name on bills), 1.11.2 and 1.11.1.

**Before rolling out,** on the counter till:

- check the version at the bottom of the sign-in screen reads 1.11.4+32;
- send an order with a kitchen item and a bar item ten times: each printer prints one slip each time;
- use Reprint on one order: each printer prints the slip again, marked REPRINT.

Only one device should have "Print ALL ... slips here" ticked for each station. Two devices
ticked for the same station still print every slip twice; that is a setting to change, not a fault.
