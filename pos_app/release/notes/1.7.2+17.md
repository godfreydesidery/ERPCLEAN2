**Needs the ERP server delivered with this version** (it records which waiter holds each table).
Update the server first. With an older server the till works, but tables cannot be moved to
another waiter.

**A table belongs to the waiter serving it.** When a waiter opens a colleague's table, the till
shows the order with "Served by Name - ask a manager to move the table to you", and they cannot
add, send, void or bill it. Cashiers and managers can still work any table.

**Move a table to another waiter.** For a shift change or a break: open the order, then More ->
Transfer to another waiter, and tap the waiter taking it over. A cashier or manager does it alone;
a waiter needs a manager to approve on the till. From then on the table, the bill, the receipt
and the waiter reports show the new waiter.

**Team service.** If your waiters share all tables, a manager can switch on "Team service - any
waiter can serve any table" in the restaurant Settings of that till.

**Who is serving? now has three choices** (restaurant Settings, managers only):

- Don't ask - orders go to whoever is signed in (as before).
- Ask before a new order - name and password before opening a table or takeaway (the old
  "Shared till: ask who is serving").
- Ask every time a table is opened - the waiter taps their name and types their password on
  every table, takeaway or order they open. The cashier confirms with their own password too.

A till that had "Shared till: ask who is serving" switched on keeps asking before a new order.

**Before rolling out,** on one till:

- check the version at the bottom of the sign-in screen reads 1.7.2+17;
- as waiter A, open a table and send an item; then as waiter B, open the same table: it shows
  "Served by A" and cannot be changed;
- as the cashier, More -> Transfer to another waiter -> B: the table now shows B, and B can add
  to it.
