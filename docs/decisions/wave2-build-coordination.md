## Contract collisions — RESOLVE before the affected (Tranche-2) branches build

1. **BLOCKER — budgeting ↔ cost-centre on `journal_lines`:** both add a cost-centre tag.
   **Resolution:** cost-centre (ADR-0025) is authoritative. Amend ADR-0034 (budgeting) to
   CONSUME `dimension_values` (drop its own `cost_centres` table + `journal_lines.cost_centre_id`
   + `LineDraft.costCentreId` + ScopeGuard `costcentre`). Makes budgeting hard-gated by cost-centre.
2. **BLOCKER — APPROVAL event name:** approvals emits `APPROVAL.SUBMITTED`/`APPROVAL.RESOLVED`;
   notifications expects `APPROVAL.PENDING`. **Resolution:** notifications consumes the existing
   `APPROVAL.SUBMITTED` (no producer change).
3. **RESOLVE — `PAYMENT.RECEIVED`:** notifications wants AR to emit it, but shipped AR doesn't.
   **Resolution:** add a one-line `OutboxPublisher.publish(PAYMENT.RECEIVED,…)` to `ArReceiptService`
   (cross-branch touch on shipped AR — do it in the notifications branch or a tiny AR patch).
4. **SOFT — project dimension prose:** amend ADR-0025 to drop the "dimension3 = Project" claim
   (projects keeps a dedicated `journal_lines.project_id` scalar; dimension3/4 stay generic-reserved).

No literal collisions on gl_config keys / CoA account codes / perms / nav routes (verified).

## Shared-file append protocol (6 platform files — make every touch ADDITIVE/APPEND-ONLY)

1. **`DomainEventType.java`** — append a `// --- <module> (ADR-00NN) ---` block of constants at the
   END (before the private ctor). Never reorder/edit existing.
2. **`ScopeGuard.java`** — append repo fields + ctor params/assignments at the end of each list;
   append `case "xxx" ->` arms before `default ->`, under a `// <Module> (ADR-00NN)` comment.
3. **`GlConfigKey.java` + `ChartOfAccountServiceImpl.DEFAULT_ACCOUNTS` + `GlConfigServiceImpl.DEFAULT_MAPPINGS`
   + the `chk_gl_config_key` CHECK** — only purchases (LANDED_COST_CLEARING/2160), sales (POS_CASH_OVER/4900,
   POS_CASH_SHORT/5170), fixed-assets (6), hr (9) touch GL config. Append enum values + map rows;
   **each migration that widens `chk_gl_config_key` must re-state the FULL union of all prior keys + its own**
   (the latest-numbered migration's union must be a superset — hr V56 must include fixed-assets' V46 keys).
4. **gl_configs / CoA back-seed migrations** — per-module, #12-safe seed-uids (`'<PFX>'||lpad(company_id,6,'0')||substr(md5(<code>),1,12)`, never `||code`). Disjoint files.
5. **`admin.routes.ts`** — append a lazy-loaded route block under `// <module> (ADR-00NN)`; disjoint path prefixes.
6. **nav shell** — append a nav-item group gated by the module's `*.VIEW` perm.
