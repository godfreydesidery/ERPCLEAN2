How I checked RBAC:
- I built an index of every `@PreAuthorize` code: 771 endpoints across 150 controllers.

## Top 5 for this area

1. **ADM-01 + ADM-28 (silent-403 empty pickers).** The cashier literally cannot do the end-of-day cash count. The pattern behind it (134 swallowed errors, 403 never surfaced) is the main "works for root, broken for staff" generator. Fix ADM-01 now. Add a per-bundle smoke test that opens every nav screen as each seeded role and fails on any 403 in a lookup.
2. **ADM-02 (no self-service password change).** Every staff password is known to the owner forever. The `must_change_password` column already exists, so this needs no schema.
3. **ADM-03 / ADM-04 (printing).** There is no web-POS receipt, every "Print" is a download, and receipts, vouchers, Z-reads, count sheets and payslips can't be printed at all. Shops run on paper.
4. **ADM-05 / ADM-06 / ADM-07 (lists).** No date filter, sort or export on any operational list. Several lists have no search, and the Sales Returns status filter is broken. This is the daily "can't find my document" hardship.
5. **ADM-12 / ADM-13 / ADM-14 (bundle fit, owner ruling plus R__seed edit).** The Branch Manager can't see AR ageing, returns or deliveries, or receive transfers. The Sales Manager can't export. Cashiers can see cost and margin. One owner-approved seed pass fixes all three.
