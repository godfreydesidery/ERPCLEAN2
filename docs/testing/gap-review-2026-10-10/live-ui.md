## Top 5

1. **LUI-01**: The stock adjustment toolbar form and "Set to counted quantity" cannot save (missing `name` causes NG01352). It is a 3-attribute fix.
2. **LUI-02**: A pack-unit LPO can't be received with the default quantity, and the PO shows bottles against crates in one row. This hits the liquor client's daily crate receiving.
3. **LUI-03**: A blocking "Something went wrong" modal appears on every finalised invoice and on unknown barcode scans. It teaches clerks that the system is broken.
4. **LUI-04 + LUI-10**: Amounts with commas are rejected or turned into 0 (with a leaked Java message), and transaction screens and the printed invoice show unformatted amounts, ISO/UTC timestamps and "0.18%" VAT (LUI-09).
5. **LUI-06 + LUI-17 + LUI-16**: After the owner follows the user setup, the new cashier still can't sell (no agent link), gets every branch by default, and must type "@default-organisation" to sign in.
